Open WebUI 연결하기

대화 관리와 사용자 계정을 갖춘 웹 화면을 Hermes의 OpenAI 호환 API에 연결합니다.

자료 확인: 2026.10.24 · 비공식 한국어 가이드 · 실제 계정 연결 및 설치 실기 검증은 포함하지 않습니다.

이 페이지에서

1. 공통 연결 준비2. Open WebUI 환경 파일 만들기3. Docker로 화면 실행하기4. 연결 확인과 첫 대화문제 해결과 종료공식 자료

명령은 내 Ubuntu 터미널에서 실행하세요. 이 가이드는 키를 입력받지 않습니다.

1. 공통 연결 준비

먼저 공통 준비부터 API 확인까지 완료하세요. 같은 Ubuntu의 Docker Engine, 브리지 주소에 바인딩한 Hermes API, API 접속 비밀키와 실제 모델 ID가 필요합니다.

연결 구성

이 안내는 Ubuntu Docker Engine의 브리지 네트워크를 사용합니다. UI는 로컬 3000 포트에 열고, Hermes에는 host.docker.internal:8642로 연결합니다.

2. Open WebUI 환경 파일 만들기

Ubuntu 터미널 · Bash
mkdir -p ~/hermes-uis/open-webui
cd ~/hermes-uis/open-webui
umask 077
touch open-webui.env
chmod 600 open-webui.env
nano open-webui.env

작업용 디렉터리는 저장소 밖에 만들고, 아래 내용으로 환경 파일을 준비하세요. REPLACE_WITH_HERMES_API_KEY를 공통 준비에서 설정한 키로 바꿉니다. 파일은 커밋하거나 공유하지 마세요.

open-webui.env · 예시 키 교체
OPENAI_API_BASE_URL=http://host.docker.internal:8642/v1
OPENAI_API_KEY=REPLACE_WITH_HERMES_API_KEY
ENABLE_OLLAMA_API=false

3. Docker로 화면 실행하기

Ubuntu 터미널 · Bash
docker run -d --name hermes-open-webui \
  -p 127.0.0.1:3000:8080 \
  --add-host=host.docker.internal:host-gateway \
  --env-file open-webui.env \
  -v hermes-open-webui-data:/app/backend/data \
  --restart unless-stopped \
  ghcr.io/open-webui/open-webui:main

공식 문서의 이미지 태그를 사용한 예시입니다. 반복 배포에서는 확인한 릴리스 태그로 고정할 수 있습니다. 첫 실행 준비 상태는 아래 로그로 확인합니다.

Ubuntu 터미널 · Bash
docker logs --tail 80 hermes-open-webui

http://localhost:3000을 열고 관리자 계정을 만듭니다. 첫 가입자가 관리자가 되므로, 본인이 먼저 설정을 마치세요.

4. 연결 확인과 첫 대화

  1. 관리자 설정의 Connections → OpenAI API Connections에서 연결을 확인합니다. 기존 설치에서는 환경 파일보다 저장된 관리자 설정이 우선할 수 있습니다.
  2. 주소는 http://host.docker.internal:8642/v1, 키는 Hermes API 접속 키입니다. API 종류를 고를 수 있으면 Chat Completions를 사용하세요.
  3. 연결을 저장하고 모델 목록에서 hermes-agent 또는 실제 API 모델 ID를 선택합니다.
  4. 새 대화에서 아래 문장을 보내고 게이트웨이 로그와 함께 응답을 확인합니다.
안녕! 한국어로 답해 줘. 파일을 바꾸거나 명령을 실행하지 말고, 네가 도와줄 수 있는 일을 간단히 설명해 줘.
도구는 Hermes가 실행합니다.

처음에는 Open WebUI의 자체 도구·Function Calling을 추가하지 말고 텍스트 대화부터 확인하세요. Hermes 내부에서 처리한 도구 진행 정보와 UI 자체 도구는 구분됩니다.

문제 해결과 종료

증상해결
새 환경변수가 반영되지 않아요관리자 Connections에서 저장된 URL·키를 수정합니다. 대화 데이터 볼륨을 지울 필요는 없습니다.
모델이 안 보여요공통 가이드의 인증된 /v1/models 호출을 확인하고 연결이 활성화되어 있는지 점검합니다.
호스트에 연결할 수 없어요공통 Docker 브리지 설정과 --add-host 옵션을 확인합니다. 루프백에만 바인딩한 API는 이 구성으로 접근할 수 없습니다.
Ubuntu 터미널 · Bash
docker stop hermes-open-webui

다시 켜려면 docker start hermes-open-webui를 실행합니다. 계정·대화는 이름 있는 볼륨에 보관됩니다. 원격 Ubuntu는 SSH 포트 전달 안내를 따르세요.
