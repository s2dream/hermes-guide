      실제 에이전트 실행하기

      GitHub Pages에서는 기존 사례를 체험합니다. 실제 검색·로그인·작업 저장은 이 저장소의 로컬 서버에서 실행합니다. 정기 실행은 설정되어 있지 않습니다.

      1. 저장소를 받은 뒤 Python 3.11 이상 환경에서 초대 토큰을 발급합니다. 발급된 토큰은 사용자에게 한 번 전달하고 보관합니다.
        python -m research_service.server add-user alice
      2. 로컬 서버를 직접 시작하고 로컬 조사 화면에서 초대 토큰으로 로그인합니다.
        python -m research_service.server serve
      3. 실제 조사는 준비된 Hermes 소스 환경, 모델 API 키와 Tavily 검색 키를 서버에 설정한 뒤 사용할 수 있습니다. 설정·검증·제한 사항 안내를 따라 설정하고 doctor로 누락을 확인하세요.
        python -m research_service.server doctor
      현재는 로컬 파일럿입니다.

      초대 사용자별 접근 검사와 작업별 Hermes 프로세스·상태 분리를 구현했습니다. 외부 다중 사용자 공개 운영을 위한 컨테이너 격리·OIDC·TLS·관리자 화면·과금 측정은 후속 작업입니다. 서버는 127.0.0.1에서만 접속할 수 있습니다.
