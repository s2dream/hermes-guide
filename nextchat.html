NextChat 연결하기

개인 채팅용 NextChat를 설치하고, 사용자 지정 모델을 Hermes API로 연결합니다.

자료 확인: 2026.10.24 · 비공식 한국어 가이드 · 실제 계정 연결 및 설치 실기 검증은 포함하지 않습니다.

이 페이지에서

1. 공통 연결 준비2. NextChat 환경 파일 만들기3. Docker로 실행하기4. 사용자 지정 모델로 대화하기문제 해결과 종료공식 자료와 연결 범위

명령은 내 Ubuntu 터미널에서 실행하세요. 이 가이드는 키를 입력받지 않습니다.

1. 공통 연결 준비

먼저 공통 준비부터 API 확인까지 완료하세요. 같은 Ubuntu의 Docker Engine, 브리지 주소에 바인딩한 Hermes API, API 접속 비밀키와 실제 모델 ID가 필요합니다.

웹 UI 기본 포트는 3001을 사용합니다. Open WebUI를 함께 실행해도 포트가 충돌하지 않습니다.

2. NextChat 환경 파일 만들기

Ubuntu 터미널 · Bash
mkdir -p ~/hermes-uis/nextchat
cd ~/hermes-uis/nextchat
umask 077
touch nextchat.env
chmod 600 nextchat.env
nano nextchat.env

작업용 디렉터리는 저장소 밖에 만들고, 아래 내용으로 환경 파일을 준비하세요. REPLACE_WITH_HERMES_API_KEY를 공통 준비에서 설정한 키로 바꿉니다. 파일은 커밋하거나 공유하지 마세요.

nextchat.env · 키와 접속 암호 교체
OPENAI_API_KEY=REPLACE_WITH_HERMES_API_KEY
BASE_URL=http://host.docker.internal:8642
CUSTOM_MODELS=-all,+hermes-agent
DEFAULT_MODEL=hermes-agent
CODE=REPLACE_WITH_A_SEPARATE_ACCESS_PASSWORD
HIDE_USER_API_KEY=1

CODE는 NextChat 화면용 별도 접속 암호입니다. API 키와 다른 임의 문자열로 바꾸세요. 이름 있는 Hermes 프로필이면 두 hermes-agent 값도 실제 모델 ID로 바꿉니다.

NextChat BASE_URL에는 /v1을 붙이지 않습니다.

NextChat가 요청 경로에 /v1/chat/completions를 붙입니다. Open WebUI·LobeHub의 주소를 그대로 복사하면 경로가 중복될 수 있습니다.

3. Docker로 실행하기

Ubuntu 터미널 · Bash
docker run -d --name hermes-nextchat \
  -p 127.0.0.1:3001:3000 \
  --add-host=host.docker.internal:host-gateway \
  --env-file nextchat.env \
  --restart unless-stopped \
  yidadaa/chatgpt-next-web

http://localhost:3001을 열고 CODE에 정한 접속 암호를 입력합니다. 이 화면은 스스로 호스팅한 NextChat이며, 공개 데모에 로컬 API 키를 입력하지 마세요.

4. 사용자 지정 모델로 대화하기

  1. 설정에서 OpenAI 계열 제공자를 사용하고 사용자 지정 모델 목록의 hermes-agent를 선택합니다.
  2. 모델 목록이 다르면 CUSTOM_MODELS와 기존 브라우저 설정을 확인합니다. 새 대화에서도 실제 Hermes 모델 ID를 선택하세요.
  3. 기존 사용자 지정 API 주소가 저장되어 있다면 서버 설정을 사용하도록 되돌립니다.
  4. 아래 문장을 보내고 Hermes 게이트웨이에 요청이 도착하는지 확인합니다.
안녕! 한국어로 답해 줘. 파일을 바꾸거나 명령을 실행하지 말고, 네가 도와줄 수 있는 일을 간단히 설명해 줘.

실제 ChatGPT 모델명 대신 Hermes가 노출하는 모델 ID를 고릅니다. Hermes가 뒤에서 사용할 모델은 기존 hermes model 설정을 따릅니다.

증상해결

접속 암호를 모르겠어요NextChat의 CODE와 Hermes API 키는 별개입니다. 본인이 지정한 화면용 암호를 사용하세요.
인증 실패 / 연결 거부공통 API 확인 명령으로 키·게이트웨이·Docker 브리지 바인딩을 점검합니다.
Ubuntu 터미널 · Bash
docker logs --tail 80 hermes-nextchat
docker stop hermes-nextchat

다시 켜려면 docker start hermes-nextchat를 실행합니다. 환경 파일 변경은 컨테이너 재생성 시 반영됩니다. 대화 기록은 브라우저 저장소에 남으므로 브라우저 데이터를 지우기 전에 내보내세요. 원격 서버는 SSH 안내의 포트를 3001로 바꿉니다.

공식 자료와 연결 범위

  • NextChat 환경변수·Docker 실행 안내
  • NextChat의 API 프록시 경로 처리 소스
  • Hermes OpenAI 호환 API

Hermes API와 NextChat의 사용자 지정 엔드포인트 기능을 조합한 텍스트 대화 안내입니다. 실제 설치 조합의 동작을 검증한 것은 아니며, 음성·이미지·자체 도구 등의 전체 호환을 뜻하지 않습니다.
