명령은 내 Ubuntu 터미널에서 실행하세요. 이 가이드는 키를 입력받지 않습니다.

먼저 준비할 것

기존 설치·모델 연결 가이드를 마치고 터미널에서 Hermes의 답변을 받은 상태로 시작하세요. 텔레그램 계정과, 계속 켜 둘 Ubuntu 컴퓨터가 필요합니다.

봇 메시지는 Ubuntu에서 실행 중인 Hermes로 전달됩니다. 컴퓨터가 꺼지거나 게이트웨이가 멈추면 답변할 수 없습니다.

1. BotFather로 봇 만들기

  1. 텔레그램 공식 @BotFather를 열고 /newbot을 보냅니다.
  2. 표시 이름과, bot으로 끝나는 고유한 사용자 이름을 정합니다.
  3. 발급된 봇 토큰을 안전하게 보관합니다. 다음 단계의 내 터미널 설정에서 사용합니다.
봇 토큰은 비밀번호처럼 관리하세요.

공유하거나 저장소에 커밋하지 마세요. 유출되면 BotFather의 /revoke로 폐기하고 새 토큰으로 설정을 바꾸세요.

2. 내 숫자 사용자 ID 확인하기

Hermes 공식 문서가 안내하는 @userinfobot에 메시지를 보내 숫자 ID를 확인합니다. @사용자이름이나 봇 ID가 아닌, 내 계정의 숫자 ID를 기록하세요.

이 ID를 허용 목록에 넣어 내 계정으로만 봇을 사용할 수 있게 합니다. 처음에는 개인 대화로 확인하세요.

3. Hermes에 연결 정보 등록하기

Ubuntu 터미널 · Bash
hermes gateway setup

메뉴에서 Telegram을 선택하고 봇 토큰과 허용할 사용자 ID를 입력합니다. 여러 사용자는 안내에 따라 등록하되, 전체 허용 기호 *는 사용하지 마세요.

설정 파일을 직접 수정하려면

기존 ~/.hermes/.env를 편집하고 아래 두 항목을 추가·수정합니다. 기존 모델 설정을 지우지 말고, 예시 값을 실제 값으로 바꾸세요.

~/.hermes/.env · 예시 값 교체
TELEGRAM_BOT_TOKEN=REPLACE_WITH_BOT_TOKEN
TELEGRAM_ALLOWED_USERS=REPLACE_WITH_YOUR_NUMERIC_USER_ID

4. 게이트웨이 실행하고 첫 메시지 보내기

Ubuntu 터미널 · Bash
hermes gateway
  1. 게이트웨이 터미널을 열어 둔 상태에서, 방금 만든 봇의 개인 대화를 엽니다.
  2. 텔레그램의 시작 버튼 또는 /start를 누르고 아래 문장을 보냅니다.
  3. 답변이 도착하는지 확인합니다. 더 많은 명령은 봇에 /help를 보내 확인하세요.
안녕! 한국어로 답해 줘. 파일을 바꾸거나 명령을 실행하지 말고, 네가 도와줄 수 있는 일을 간단히 설명해 줘.
이미 게이트웨이가 실행 중이라면

기존 프로세스를 종료한 뒤 다시 실행해 설정을 적용하세요. 같은 봇 토큰으로 게이트웨이를 여러 개 띄우지 마세요.

5. 계속 실행하기와 그룹 사용

터미널을 닫아도 계속 사용하려면 게이트웨이를 서비스로 운영할 수 있습니다. 먼저 개인 대화 연결을 확인한 뒤 아래 도움말에서 설치 환경의 지원 옵션을 확인하세요.

Ubuntu 터미널 · Bash
hermes gateway --help

상시 실행 방식은 공식 Messaging Gateway 문서를 참고하세요. 서비스와 수동 실행을 중복으로 켜지 마세요.

그룹에서는 봇을 초대하고 @봇사용자이름으로 먼저 호출해 보세요. 개인 대화와 달리 메시지 전달·호출 조건이 적용됩니다. 모든 그룹 메시지가 필요한 경우에만 BotFather의 /setprivacy를 검토하고, 변경 후 봇을 그룹에서 제거했다가 다시 추가하세요.

연결이 막힐 때

증상확인할 내용
아무 응답이 없어요게이트웨이가 실행 중인지, 봇 토큰이 유효한지, Ubuntu에서 Telegram에 접속할 수 있는지 확인합니다. 먼저 hermes doctor와 게이트웨이 로그를 확인하세요.
unauthorized가 나와요TELEGRAM_ALLOWED_USERS에 내 숫자 ID가 있는지 확인하고 게이트웨이를 다시 시작합니다.
Conflict / getUpdates 오류같은 토큰을 쓰는 다른 게이트웨이 또는 봇 프로그램을 종료합니다.
개인 대화는 되지만 그룹은 안 돼요봇 멘션, Telegram privacy 설정과 Hermes 허용 목록을 확인합니다. 그룹 전체 권한은 모든 구성원에게 에이전트 접근을 줄 수 있습니다.
토큰이 유출됐어요BotFather에서 토큰을 폐기·재발급하고 Hermes 설정을 교체합니다.
